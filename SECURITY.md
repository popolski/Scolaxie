# Sécurité

Ne publiez jamais de secret, de base de production, de données d'élèves, de journal de session ou de capture de recette. Placez les valeurs locales dans des fichiers ignorés par Git. Vérifiez aussi l'historique Git avant tout partage : `.gitignore` n'efface pas les anciens commits.

Ce candidat est incomplet. Il ne dispose pas encore de procédure d'installation sûre ni de canal public de signalement de vulnérabilités.
